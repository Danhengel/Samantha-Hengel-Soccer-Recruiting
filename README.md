# Samantha Hengel Soccer Recruiting

This repository is the source for Samantha Hengel's Class of 2028 recruiting website. The site is a static HTML/CSS/JavaScript project; `index.html` is the homepage. Changes to the `main` branch deploy to the connected Vercel project.

The site includes player profile, film, schedule, academics, and recruiting contact pages.

Deployment refreshed September 29, 2026.
